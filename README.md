# Apex Universal Studios™ — Official Website

A modern, responsive website for **Apex Universal Studios™**, a diversified entertainment, media, and technology company building original IP and enduring creative businesses.

## 🌐 Overview

This repository contains the official corporate website for Apex Universal Studios™. The site showcases:

- **Company Identity** — Apex’s mission, vision, and values
- **Divisions & Businesses** — 6 specialized business areas (Animation, Pictures, Music, Labels, Games, Software)
- **Creative Development** — Technical capabilities and production infrastructure
- **IP & Properties** — Long-term intellectual property strategy
- **Company Announcements** — News and development updates
- **Founder Identity** — Connection to founder Faruq Ayomide Ojolowo

## 🚀 Quick Start

### Local Development

1. Clone the repository:

```bash
git clone https://github.com/yourusername/apex-universal-website.git
cd apex-universal-website
```

1. Open `index.html` in your browser:

```bash
open index.html
# or
python -m http.server 8000
```

1. View at `http://localhost:8000`

### GitHub Pages Deployment

1. Push code to GitHub repository
1. Go to **Settings** → **Pages**
1. Select `main` branch as source
1. Site will be available at `https://yourusername.github.io/apex-universal-website`

## 🔧 Customization

### Colors

Edit `:root` variables in `styles.css`:

```css
:root {
    --primary-bg: #0a0e27;
    --accent-color: #00d4ff;
    --text-primary: #ffffff;
    /* etc */
}
```

### Content

Edit sections directly in `index.html`. Each section is clearly commented.

### Images

Replace placeholder divs with actual images:

```html
<!-- Current -->
<div class="hero-placeholder">[Background Image Placeholder]</div>

<!-- Replace with -->
<img src="assets/hero-bg.jpg" alt="Hero background">
```
